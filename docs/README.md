# Documentation

This directory contains the documentation for users and future maintainers of
`taskwarrior-textual`.

## Start here

- [Tutorial](tutorial.md) — install the application, configure it, learn the
  interface, and complete a first planning workflow.
- [Use cases](use-cases.md) — practical workflows for daily task management,
  project planning, dependencies, auto-scheduling, Timewarrior, and planning
  diagnostics.
- [Maintainer guide](maintainer-guide.md) — architecture, invariants, code
  organization, development workflow, testing, quality gates, and extension
  patterns.

The short project overview remains in the repository [README](../README.md).
The in-application reference is available at any time with `?`.
